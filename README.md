RiskRise
FidHacks 2024 - 2nd place

RiskRise was built to solve a problem we’ve all felt: personal finance is intimidating. Between the jargon and the genuine fear of losing money, many people—especially students—stay on the sidelines. We built this to create a low-risk environment where you can learn by doing.

We also wanted to address a massive gap in financial education: the unique hurdles women face. From planning for a longer life expectancy to navigating systemic bias in lending, RiskRise integrates these real-world scenarios into the gameplay.

How it Works
You start your "life" at age 18. You customize a character, receive a monthly salary based on your financial standing, and decide how to invest it.

Live Market Data: We integrated the Tiingo API so you’re trading against real-world stock movements.

Knowledge Gates: You can’t just buy a house—you have to pass a mortgage quiz first. It links your financial literacy directly to your "lifestyle" upgrades in the game.

Legacy System: Your ending balance determines how much "generational wealth" you pass on to your next character.

The Tech Stack
Frontend: HTML, CSS, and Vanilla JavaScript.

Backend: Python and Flask.

Data: Tiingo API for live market prices.

Environment: Built and debugged in VS Code.

The Real Story: Challenges and Wins
This project was a steep learning curve for our team:

The JavaScript Wall: None of us knew JavaScript when the hackathon started. We spent the first few hours just figuring out the syntax so we could make the UI interactive.

The Python-to-Web Bridge: We had a solid investing script written in Python, but getting it to talk to an HTML frontend via Flask was a huge technical hurdle for us. Seeing those two sides finally sync up was our proudest moment.

API Integration: Learning how to pull live data from an API and parse it in real-time gave the game the "real" feeling we were aiming for.

What’s Next
We want to clean up the UI to make it feel more "gamey" and aesthetic. Right now, the finance quizzes and the investing game are two separate parts; our next goal is to link them more tightly so your quiz performance directly impacts your market returns.
